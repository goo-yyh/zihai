# Security policy

Please report vulnerabilities privately to the repository owner. Do not include secrets, personal data, or working exploits in a public issue.

Include the affected route or feature, impact, reproduction steps, and any suggested mitigation. The maintainer will acknowledge the report, validate severity, and coordinate remediation before public disclosure.

Supported security fixes target the current `main` branch. Dependencies are locked with `pnpm-lock.yaml`, and pull requests must pass lint, type, unit-test, and production-build checks.
